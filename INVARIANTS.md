# Invariants

Rules whose breach is a design change, not a fix; changing one is the owner's decision.

- A plugin's description here, in the README listing and in `.claude-plugin/marketplace.json`, follows that plugin's own manifest: the manifest is the description's home, and this repo mirrors it. A description edited here first gives the same pitch two authors, and the marketplace then advertises a plugin its own manifest no longer describes. The log shows the mirroring done by hand each time a manifest moves; that direction, manifest first, is the rule.
